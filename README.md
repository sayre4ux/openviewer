# OpenViewer

OpenViewer is a small Markdown editor built with Tauri 2 and CodeMirror 6 live preview. It keeps Markdown byte-faithful, reveals syntax markers at the caret, and stays small and fast.

Run the desktop app with `npm run tauri dev`, or build it with `npm run tauri build`.
