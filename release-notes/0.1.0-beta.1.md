The first public beta of OpenViewer, a Markdown editor for macOS that works like Typora and looks like its Newsprint theme.

## What's in it

- Live preview: Markdown renders as you type, and the markers come back while the cursor is inside them. ⌘/ switches to plain source.
- Files are saved byte for byte: line endings, a UTF-8 BOM, and legacy encodings such as Big5, GBK, and Shift_JIS are kept.
- Tables you can edit in place, with Tidy to line up the columns.
- Images pasted or dragged in are copied next to the document. Images from the internet stay off until you turn them on in Settings → Images.
- Math with KaTeX, and Mermaid diagrams drawn in a sandboxed frame.
- Export to PDF or to a single self-contained HTML file.
- Outline sidebar, focus mode, typewriter mode, word count, and custom shortcuts.
- English, 繁體中文, 简体中文, and 日本語.
- Updates: the app checks for new versions and asks before installing one.

## Installing

Download the `OpenViewer-0.1.0-beta.1-universal.zip` file below, unzip it, and move OpenViewer to Applications. It runs on Apple silicon and Intel Macs.

This beta isn't signed with an Apple Developer ID yet, so macOS blocks the first launch. Open it once, then go to System Settings → Privacy & Security and click **Open Anyway** next to the message about OpenViewer. You only need to do this once.

## Known limits

- No dark mode yet.
- This is a beta. Keep backups of documents you care about, and report problems at https://github.com/sayre4ux/openviewer/issues.
