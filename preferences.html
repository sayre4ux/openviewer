Images from the internet

When this is on, opening a document downloads every web image in it. Whoever runs the server behind an image learns that the document was opened and when, and sees your IP address, which shows roughly where you are. An image can work as a hidden read receipt, even in a document that looks harmless, and its server may recognize you again later through what OpenViewer keeps in its cache. A server can also redirect the request to a device on your own network, such as a router or printer, and OpenViewer can’t fully block that yet.

Turn this on only if you trust the documents you open. When it’s off, a web image shows as a note naming its server, and export leaves it out. Images stored with the document always show.
